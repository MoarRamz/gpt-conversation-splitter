Microsoft Runtime and Windows Component Notices

LLM Continuity Toolkit is published as a self-contained Windows application and redistributes Microsoft .NET / WPF runtime components required to run the application without a separately installed .NET runtime.

The release pipeline copies the license and third-party-notice files supplied with the pinned Windows .NET installation into each official portable package and validates that the supplied Windows .NET license identifies the .NET Library License.

Microsoft's current .NET license information for Windows identifies the following distributed components as subject to the .NET Library License:

- .NET runtime components embedded in the single-file application executable
- PresentationNative_cor3.dll
- vcruntime140_cor3.dll
- wpfgfx_cor3.dll

Microsoft identifies D3DCompiler_47_cor3.dll as subject to the Windows SDK License. Current Microsoft deployment guidance states that D3DCompiler_47.dll may be included as a simple application-local file for non-Store applications.

PenImc_cor3.dll and other .NET binaries/files not listed by Microsoft as Windows-specific exceptions remain subject to the licenses and notices identified by Microsoft and their respective copyright holders.
